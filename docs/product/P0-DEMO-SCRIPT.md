# PLDR P0 三分钟演示脚本

## 0:00 至 0:30，说明系统边界

打开首页。指出当前专题是苏伊士运河阻塞公开事件演示快照，用于验证证据链和工作流。顶部显示 16 个来源、48 篇文档、8 个事件、24 条主张和 56 条证据。

一句话定位：PLDR 把散落网页整理成事件、主张和可回溯证据，地图只是其中一个观察入口。

## 0:30 至 1:05，展示事件中心

点击时间线中的事件，指出这个 Event 下有多篇文档，但独立来源组少于文档数。页面会把转载或共同上游折叠，避免把重复报道当成多源确认。

## 1:05 至 1:45，展示主张与冲突证据

打开事件档案，查看争议主张。先点支持它的报道，再点反证。展示证据片段、来源、独立来源组、发布时间、抓取时间和 SHA-256。

点击带高亮的原文快照，说明证据必须是正文精确子串，找不到原文的模型输出不能进入 Evidence。

## 1:45 至 2:20，展示结构化研判

回到首页，查看当前研判中的关键假设、替代解释、信息缺口和证伪条件。

强调机器主张、人工复核和最终研判分层保存。系统会展示不确定性，不把一个风险分数直接包装成事实。

## 2:20 至 2:50，生成报告

选择事件并生成证据简报。报告展示事件时间线、关键主张、证据索引、信息缺口和证伪条件。点击证据链接回到快照。

## 2:50 至 3:00，说明下一步

当前 P0.2 已证明既有闭环。唯一下一步是 P0.3：让网页、粘贴文本和本地文件先进入待处理采集箱，由 AI 生成候选对象，经分析员新建、合并、修改或驳回，确认后再进入正式事件档案与可追溯报告。连续运行和规模扩展在 P0.3 验收后进入 P1。
