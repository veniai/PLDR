# P0 专题包模板

## 专题名称

待定。

## 需要回答的五个问题

1. 过去 24 小时发生了什么变化。
2. 哪些来源首次报道，哪些来源属于转载或共同上游。
3. 主要参与者和地点是什么。
4. 各来源对关键事实有哪些一致与冲突。
5. 目前最重要的信息缺口和待核实问题是什么。
