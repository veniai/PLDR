# 参考项目与使用边界

| 项目 | 主要用途 | PLDR 阶段 | 使用方式 | 许可证或边界 |
| --- | --- | --- | --- | --- |
| Palantir Foundry/AIP | 对象化、动作、分析追溯 | 全阶段 | 学习产品与架构思想 | 闭源参考 |
| World Monitor | 态势界面、来源健康、多信号关联 | P0 起 | P0 前端外壳，新增 `pldr` 变体 | AGPL，长期派生边界需复核 |
| BettaFish | 多模块分析与报告 | P0 起 | 学习流程和报告体验 | GPL-2.0，谨慎复用 |
| MiroFish | 群体仿真与预测 | P4 | 研究候选 | AGPL，输出需评估与回测 |
| MiroFlow | 深度研究 Agent | P2 起 | 独立研究服务候选 | Apache-2.0 |
| MiroThinker | 长链研究模型 | P2 起 | 模型候选 | Apache-2.0 |
| Crawl4AI | 动态网页抓取 | P1 起 | Connector 或独立执行器 | Apache-2.0 |
| RSSHub | 补充 RSS 路由 | P2 起 | 独立服务 | AGPL |
| OpenCTI | 来源、关系、置信度、本体 | P3 参考 | 学习模型和连接器 | 社区与企业目录需区分 |
| OpenAleph | 文档库和实体检索 | P3 候选 | 独立调查资料库 | MIT |
| FollowTheMoney | 调查实体模型 | P2 起 | 借鉴实体规范 | MIT |
| ArchiveBox | 网页证据归档 | P2 起 | 独立归档服务 | MIT |
| changedetection.io | 页面变化监控 | P2 起 | 独立监控服务 | Apache-2.0 |
| LiteLLM | 多模型网关 | P2 起 | 独立网关 | 核心 MIT，企业目录另计 |
| Langfuse | LLM 追踪与评估 | P2 起 | 独立观测服务 | 核心 MIT，企业目录另计 |
| NewsNow | 新闻 UI 与来源适配 | P0 参考 | 视觉与代码组织参考 | MIT |

正式采用任何项目时，以实际 commit、LICENSE、NOTICE、企业目录和部署方式为准。
